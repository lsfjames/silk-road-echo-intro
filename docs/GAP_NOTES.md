# 已知限制 Gap Notes

诚实边界，面试可直接用：

1. **无自动化测试** — 仅有构建检查与手工/API 冒烟；生产项目应补 Playwright E2E + 单测。  
2. **Live AI 未在本环境用真实 Key 贯通验证** — 代码区分 Live/Demo，当前演示走 Demo。  
3. **站外数据不能自动抓取** — 产品设计为回填+核验；若合作方提供开放 API 可扩展 `ExternalMetric` 同步源。  
4. **视频存本地磁盘** — 不适合生产；应换对象存储 + CDN + 转码。  
5. **SQLite** — 演示友好；并发与备份需 PostgreSQL。  
6. **未做**：通知系统、创作者激励自动发放、推荐算法、移动端 App。  
7. **安全**：生产需 HTTPS、CSRF 策略强化、上传杀毒、审计日志。  
8. **公开仓不含源码** — 评鉴如需完整代码，可要求私有仓只读访问或演示。
