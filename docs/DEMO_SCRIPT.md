## 可能被追问 · 准备

**Q: 为什么不用自动抓取小红书播放？**  
A: 无稳定开放接口且存在合规风险；用创作者回填 + 凭证 + 人工核验，`sum` 只计 verified。

**Q: AI 是你训的吗？**  
A: 不是。做的是 **应用层**：统一适配 OpenAI 兼容 API、演示降级、溯源与风险工作流。训练/对齐明确未做。

**Q: 权限怎么做的？**  
A: JWT httpOnly Cookie + bcrypt；接口层 `requireUser` + mentor/admin 才能审核核验。

**Q: 有测试吗？**  
A: 目前有构建 + API 冒烟与手工主路径；**自动化单测未实现**（已写入验证文档，不回避）。
