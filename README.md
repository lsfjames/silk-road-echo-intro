# 丝路回响 · Silk Road Echo

**丝路回响——面向来华留学生的 AI+OPC 跨文化共创与地域文化双向传播平台**

> 让来华留学生成为民间外交使者，用 AI 把中国地域文化讲给世界听。  
> 让世界听见丝路回响。

---

## 一句话介绍

面向来华留学生的跨文化共创与内容出海平台：中外青年结对共创，沿 OPC 六阶段孵化地域文化 IP，短视频「投稿 → 管理审核 → 发布」闭环，并支持小红书 / 抖音 / YouTube 等**站外传播数据回填与核验**。

---

## 核心能力

| 模块 | 说明 |
|------|------|
| 结对共创 | 留学生 × 中国学生结成创作小队 |
| 文化 IP 孵化 | 草原游牧 / 城市文脉 / 非遗 / 生态文旅 |
| OPC 六阶段 | 立项 → 素材采集 → 创作 → 多语适配 → 发布 → 复盘 |
| AI 创作工坊 | 多语种叙事优化 · 跨文化风险预警 · 本土化重塑 |
| 视频投稿与审核 | 竖屏类抖音信息流，审核通过后公开 |
| 站外数据回流 | 播放/点赞回填 + 凭证 + 管理员核验 |
| 多语言 | 中文 / English / Русский |
| 治理底线 | 青年为主、AI 为辅；人机内容溯源 |

---

## 技术栈

- **前端 / 全栈：** Next.js 14 App Router · TypeScript · React 18 · Tailwind CSS
- **数据：** Prisma · SQLite（可切换 PostgreSQL）
- **鉴权：** JWT Cookie · 四角色权限
- **AI：** OpenAI 兼容接口 · 无 Key 演示降级 · 溯源落库
- **工程：** 一键 seed · 生产构建通过 · 本地零依赖可演示

---

## 产品结构（Demo 路径）

1. 首页品牌与旗舰 IP「双城信使」
2. 结对共创 / 文化 IP / 共创项目（OPC）
3. 视频流 `/feed` → 投稿 `/upload` → 审核 `/review`
4. AI 工坊三工作流 + 使用规范
5. 作品详情：多语种切换 + 站外传播回流
