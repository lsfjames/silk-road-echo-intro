# Silk Road Echo

**Silk Road Echo — AI + OPC cross-cultural co-creation and two-way regional culture platform for international students in China**

> Let international students become people-to-people ambassadors. Use AI to tell China's regional stories to the world — and bring global stories home.  
> Let the world hear the echo of the Silk Road.

---

## What it is

A full-stack platform where international students and Chinese peers co-create cultural content, incubate regional culture IPs, publish short videos through a moderated UGC pipeline, and report off-platform reach (Xiaohongshu, Douyin, YouTube, VK, etc.).

---

## Key features

| Module | Description |
|--------|-------------|
| Pairing | International × Chinese student co-creation squads |
| Culture IP lab | Nomadic steppe / urban heritage / intangible culture / eco-tourism |
| OPC path | Ideation → collect → create → localize → publish → review |
| AI studio | Multilingual narrative · cross-cultural risk check · localization |
| Video pipeline | Upload → admin review → vertical feed (TikTok-style) |
| Reach reporting | External views/likes backfill + link proof + admin verification |
| i18n | Chinese / English / Russian |
| Governance | Human-led, AI-assisted; provenance for every generation |

---

## Tech stack

- **App:** Next.js 14 (App Router) · TypeScript · React 18 · Tailwind CSS  
- **Data:** Prisma · SQLite (PostgreSQL-ready)  
- **Auth:** JWT cookies · four roles (intl student / CN student / mentor / admin)  
- **AI:** OpenAI-compatible API · graceful demo mode without a key · provenance logs  
- **Ops:** One-command seed · production build verified · local demo with zero external deps
